# Comedian Voices

Agent skills for writing in the voice of famous stand-up comedians, generated by a pipeline that turns raw source material (books, special transcripts) into loadable skills.

Each skill codifies the **structural moves**, **rhetorical patterns**, and **anti-patterns** extracted from close analysis of a comedian's published work. Load a skill and an agent can produce writing that reads like that comedian — not by imitation of surface jokes, but by reproducing the underlying machinery of how they build, pace, and land material.

## How it works

```
source/<slug>/     raw books/transcripts (gitignored, stays local)
       │
       ▼
pipeline/          ingest → extract → analyze → assemble
       │
       ▼
skills/<slug>/     SKILL.md + <slug>-style-analysis.md (committed)
```

The pipeline (`pipeline/`) automates scaffolding, copyright-flagged excerpt extraction, and template assembly. The analysis itself — extracting the voice, architecture, and rhetorical machinery — is agent-driven using the writeprint generator (`writeprint/writeprint-generator.md`).

**Transcribing video/audio** — drop media in `source/<slug>/raw/` and run the standalone Whisper transcriber (`pipeline/scripts/transcribe.py`) to produce timestamped text, then run the pipeline on it:

```bash
python -m pipeline.scripts.transcribe source/<slug>/raw --output-dir source/<slug>/transcripts
```

See `pipeline/scripts/INSTALL.md` for setup.

**Copyright:** raw books/transcripts are never committed. The pipeline flags full works and only short, attributed excerpts end up in the committed skill. See `pipeline/references/fair-use.md`.

## What a skill contains

Every comedian skill is a two-part pair:

- **`<slug>-style-analysis.md`** — the deep source analysis: voice & tone, comedic architecture, sentence-level mechanics, rhetorical moves, linguistic fingerprints, thematic obsessions, anti-patterns, excerpt index.
- **`SKILL.md`** — the loadable, distilled version agents apply immediately.

## Usage

Point your agent at the relevant skill folder, or copy the `SKILL.md` into your agent's skill directory.

## Adding a new comedian

See [CONTRIBUTING.md](CONTRIBUTING.md):

```bash
# 1. Drop raw material into source/<slug>/
# 2. Scaffold + extract
python -m pipeline.scripts.preflight --config pipeline/config.example.json
python -m pipeline.scripts.run_pipeline --config pipeline/config.example.json --item <slug>
# 3. Analyze (agent-driven, using the writeprint generator)
# 4. Assemble + validate
python -m pipeline.scripts.run_pipeline --config pipeline/config.example.json --item <slug> --only assemble
```

## Structure

```
comedian-voices/
├── README.md
├── CONTRIBUTING.md        # adding a new comedian
├── skills/
│   ├── _template/         # reusable scaffold (SKILL.md + analysis + fair-use)
│   └── <comedian-slug>/   # generated skills
│       ├── SKILL.md
│       └── <slug>-style-analysis.md
├── source/                # raw books/transcripts (gitignored)
├── writeprint/
│   └── writeprint-generator.md
└── pipeline/
    ├── SKILL.md
    ├── config.example.json
    ├── scripts/           # deterministic phases (python)
    └── references/        # fair-use policy, dev guide
```
